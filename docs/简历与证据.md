# 简历与证据

项目名：基于 OpenHand T42 的夹爪支承顶板轻量化与刚度校核

- 基于 OpenHand T42 建立手指支承顶板的参数化改型，保留安装接口，比较三种凹槽深度并输出 STEP/STL、改制尺寸图和设计说明。
- 围绕竖向、撑开和弯矩三种参考工况开展二次四面体有限元对照；候选方案实体体积减少 5.53%，最不利工况柔度增加 8.20%。
- 完成独立梁算例、网格细化和平衡残差检查；最终两档网格的柔度变化不超过 0.66%，明确材料假设及零件级验证范围。

# 打样、加载及耐久试验计划

状态：方案已准备，**尚未执行**。表内阈值是本项目拟定的验收标准，需随用途和工艺评审；不属于官方产品指标。建立与原始件同批、同工艺、同方向的对照，所有量具记录量程、分辨率和校准状态。

| 阶段 | 做什么 | 记录与判定 |
|---|---|---|
| 孔径试块 | 打印提供的 70×36×8 mm 试块，按缺口确定方向；分别沿两方向量孔，试装实测销 | CAD 孔径与实测孔径逐一记录；据此确定毛坯孔，不预设固定收缩率 |
| 几何检验 | 原始件、Rev B 各至少 3 件；检查槽、支座宽度、销孔、底板与凹槽深度 | 底厚各槽多点 ≥1.20 mm；槽配合、销孔范围见工艺说明；不合格件先返修或重制 |
| 回位件标定 | 从声明的零位逐级改变关节角，测弹簧力/力矩及卸载曲线 | 拟合 τ(q)，记录预紧、迟滞和重复性；若不符合研究中的 20/40 N·mm/rad，则更新静力模型 |
| 腱绳损耗 | 执行器端与手指端布置张力测量，覆盖拟用姿态及速度 | 记录张力比、绕线层数与滑移；不得用电机“负载百分比”直接冒充张力 |
| 空载装配 | 手动和低速走完规定路径，检查实际弹簧、绳、螺钉、垫层与下部件 | 无卡滞、绕线跳槽；角度限位先设在模型检查范围内，再按实物减小范围 |
| 顶板位移对照 | 使用与等效 FE 相同的夹持边界和座面力/力偶，分 25%、50%、75%、100% 加载，原始与 Rev B 同夹具测量 | 每级保载并卸载，记录座面位移和残余位移；拟定残余 ≤0.05 mm、修订件柔度增幅 ≤10%；超出先查边界、材料与装配 |
| 模型相关性 | 用已标定材料及夹具刚度预测同一测点位移 | 拟定预测与测量偏差 ≤15%；未满足时不得继续引用未修正模型作额定载荷依据 |
| 双接触力 | 用可测接触力的专用物体或夹具实现研究接触点，逐级增加张力 | 检查接触是否脱开、法向力及重复性；实际物体变化后需重新验证，不能外推到所有物体 |
| 持续载荷 | 在目标占空比下记录 1、10、30、60 min 位移、温度和驱动状态 | 首次试验拟定 60 min 位移增长 ≤10%，不得超设备厂家限值；不是长期蠕变寿命证明 |
| 初步耐久 | 先 100 次调试，再按目标工况做 1,000 次筛查，定期检查销松动、裂纹及绳磨损 | 记录循环次数、漂移和失效模式；1,000 次只是筛查，不能写成额定寿命 |

## 数据与图纸交接

- `results/engineering/test_record_template.csv` 是空白原始记录模板，不能在未试验时填写“合格”。
- 原始 CSV/照片保留试件编号；称量应注明电子秤分辨率，区别实体估算质量与实测质量。
- 外部试验数据到位后，使用同一零位、单位、坐标、载荷系数更新 `engineering.json`，再运行静力与有限元脚本。
- 优先做孔径试块和回位件标定。这两步决定精配合能否成立，以及现有力计算是否适用于最终装配。

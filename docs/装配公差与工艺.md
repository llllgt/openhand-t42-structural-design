# 装配、公差与制造方案（Rev B）

本版完成数字设计及工艺规划，所有公差都是拟定的成品验收目标，尚无制造能力或过程能力指数证据。单位为 mm。顶板、支座与手指的最终尺寸 CAD 位于 `cad/engineering`；原始 STEP 仍保留在 `cad/upstream`。

## 装配基准与干涉检查

顶板保留原坐标，中心为 X/Y 基准，顶面 Z=0.003、底面 Z=−2.997。支座法兰上表面与顶板底面重合，右支座宽度中心 X=31.3、Y=0；左侧绕 Z 轴镜像布置。近端轴线由销孔圆柱轴恢复，远节按近端销轴、远端销轴及纵向平面定位。此为重新定义约束的 STEP 上部装配，未恢复 SolidWorks 原生装配配合。

源模型关节扫描发现：近端 0°/5°/10° 存在相交，15° 样点开始无相交；远端 90° 样点无相交，95° 样点出现约 8.78 mm³ 相交，100° 时约 161.38 mm³。对称的 85°/90° 姿态还会发生左右远指相撞。这些是几何采样结果，不是精确连续限位角。

修订后的上部刚体模型沿规定闭合路径抽查 **39 个姿态、每姿态 9 对零件，共 351 对检查**，采用 B-rep 实体求交，结果见 `closure_sweep.json`。未检查点之间的连续扫掠没有数学证明；腱绳、弹簧、垫层、紧固件头部和执行器下部不在本次碰撞模型中。不能写成“整机全行程无干涉”。

## 尺寸链一：最小底厚

原方案名义底板 t=3.0、凹槽 d=1.8，名义剩余厚度 1.2。若底板允许 ±0.15，而凹槽深度为 +0/−0.15，最不利底厚仅为 2.85−1.80=**1.05**。仅标注名义值无法保证 1.2 的目标。

Rev B 将凹槽改为 **1.65 +0/−0.15**，底板仍按 **3.0±0.15** 管控：

```
t_floor,min = 2.85 − 1.65 = 1.20
t_floor,max = 3.15 − 1.50 = 1.65
```

仍须在每个凹槽检查实际剩余底厚 ≥1.20。原方案不是因为计算强度“失败”而废弃，而是本版增加了制造公差要求。新的 CAD 体积减少约 **5.07%**；旧版 **5.53%** 仅属于 1.8 mm 方案，不能混写到新版上。

## 尺寸链二：支座插入间隙

源模型槽长为 31.90，支座外宽 31.75，名义总间隙只有 0.15。若双方均为 ±0.15，最不利会出现 −0.15 的间隙，即干涉。

本版保持顶板接口几何，将支座两侧成品外宽修订为 **31.60±0.05**，槽的成品检验目标为 **31.90±0.05**，总间隙为 **0.20–0.40**。支座 STEP 已修窄；槽可能需要清理与后加工才能达到目标。名义对中时单侧约 0.15，但浮动装配不保证实际左右各占一半。该尺寸只控制装入，不单独承担定位与力矩传递。

## 尺寸链三：销孔固定与转动配合

原始 CAD 固定侧孔直径 6.50、转动侧孔直径 7.05，名义销为 6.35。原模型含打印补偿，不能把这些 CAD 尺寸称作标准过盈与间隙配合。[官方手指指南](https://www.eng.yale.edu/grablab/openhand/OpenHand%20Finger%20Guide.pdf)亦要求按配合用途清理、铰孔。

| 项目 | 拟定成品范围 | 尺寸链结果 |
|---|---:|---:|
| 实测选配销 | 6.344–6.350 | 采购和到货检验要求，非标准公差代号 |
| 固定侧孔 | 6.325–6.340 | 直径过盈 0.004–0.025 |
| 转动侧孔 | 6.375–6.400 | 直径间隙 0.025–0.056 |

`bracket_revB.step`、`finger_A_finished.step`、`finger_B_finished.step` 已按成品孔的中值建模。固定孔与旋转孔分开标识，不虚写为未经查证的 H7/h6 等标准配合。过盈在所选聚合物中的装配力、开裂及长期松脱仍需打样验证。

**这些是后加工成品 CAD，不是可直接照用的打印补偿尺寸。**先打印 `pin_fit_coupon`，测量孔的实际收缩与椭圆度，再决定毛坯孔。后加工前孔应小于最终尺寸；孔已经过大时，铰孔不能补救，应重打或改为经设计的衬套。未获得试块数据前，不发布孔补偿系数。

## 材料与工艺选择

| 路线 | 依据 | 用途与取舍 |
|---|---|---|
| PETG / FFF | [Prusament 数据表](https://storage.googleapis.com/prusa3d-content-prod-14e8-wordpress-prusament-prod/2023/10/9f8d2165-tds_prusament-petg_n_en.pdf)：试样拉伸模量约 1.5/1.6 GPa、密度 1.27 g/cm³ | 先用于装配、孔径补偿和工艺试块；方向性、薄底层和孔尺寸需复核 |
| PA 2200 / SLS | [EOS Balance 数据表](https://www.eos.info/polymer-solutions/data-sheets/pds-pa-2200-balance)：拉伸模量 1650 MPa、密度 0.93 g/cm³，干态拉伸强度 X/Y/Z 为 48/48/42 MPa | 选为功能样件的候选工艺；便于复杂内腔，但仍需后加工孔、湿态与批次验证 |

这次新增有限元用 E=1650 MPa、ν=0.35；前者有资料依据，泊松比及各向同性仍为近似。没有完整正交弹性参数时不编造各向异性材料卡。厂商拉伸强度不是自动可用的零件许用应力；不把干态试样值当作长时、湿态、缺口零件的寿命保证。

建议的样件工序：材料与批次记录 → 孔径试块 → 尺寸补偿 → 顶板/支座/指节成形 → 清粉或去支撑 → 基准面及槽检查 → 按孔类别后加工 → 实测销选配 → 干装配 → 安装回位件与腱绳 → 校准零位 → 分级加载。打印方向与供应商确认并记录，不能只凭“100% 填充”替代材料性能确认。

## 销轴及耳板的强度需求筛查

在等效弹簧力偶模型下，采用载荷包络 P=1.5(3T+N₁+N₂)≈108.91 N，最小销径 6.344，支承跨度 27.6，单耳厚 4.15，做简支中央载荷与双剪估算：

- 双剪应力约 **1.72 MPa**；弯曲正应力约 **29.98 MPa**。
- 以 2 倍裕量需求表达，所供销材的屈服依据至少应覆盖约 **60.26 MPa** 的组合应力需求。
- 耳板名义承压约 **2.07 MPa**，两倍需求约 **4.14 MPa**。

这是需求筛查，不是材料认证或整套关节强度放行。真实拉簧锚点带来的附加力、销的约束分布、耳根缺口、压入残余应力及疲劳未包含；需在具体弹簧和工艺确定后补核。公式、输入及输出保存在 `mechanism.json`。

# 双转轴欠驱动夹爪：机构与传力分析

本文件是基于开源机构的二次分析。新增工作是参数提取、装配重建、运动与静力计算、设计修订及数值复核；原始机构并非个人原创。以下接触物、弹簧参数、摩擦效率是设计研究输入，不是对上游实物性能的复现。

## 1. 对象与参数依据

选用 Pivot-Pivot 双转轴手指，两个手指分别由一个执行器牵引腱绳，弹簧负责回位。机构类别与装配依据为 [Yale 手指指南](https://www.eng.yale.edu/grablab/openhand/OpenHand%20Finger%20Guide.pdf) 和 [T42 装配指南](https://www.eng.yale.edu/grablab/openhand/model%20t42/Fabrication%20-%20Model%20T42%201.0.pdf)。STEP 固定版本为 `b10197dcd79e7bcfa92c6d5a0bfa479e6a789fba`。

- 近端两销轴中心从 `finger_pp_ext_A_t42.STEP` 的圆柱轴线提取，中心距 **62.5 mm**。不能用圆柱面的面积重心代替轴心。
- 远端名义长度 **37.5 mm**、两关节名义传动半径 **8 mm** 来自 [CAD Guide](https://www.eng.yale.edu/grablab/openhand/OpenHand%20CAD%20Guide.pdf) 的参数表；传动半径采用常数近似，未求解腱绳绕销滑动的完整接触路径。
- 执行器卷线件 STEP 的槽底半径为 **10.5 mm**；研究采用直径 0.5 mm 腱绳，单层绕线有效半径为 **10.75 mm**。
- `engineering.json` 明确区分来源尺寸与新增研究假设；所有计算输出在 `results/engineering`。

## 2. 自由度、坐标与运动学

单指有地件、近节、远节三个构件和两个平面转动副：M = 3(3−1)−2×2 = **2**。两指合计 4 个几何自由度、2 个驱动输入。绷紧且给定长度的单根腱绳给单指施加一个标量约束，还剩一个由弹簧、限位及接触决定的被动构型自由度。弹簧不减少几何自由度。

右指的 X 正方向向外，Z 正方向向上。q₁ 从向外水平线逆时针计，q₂ 是远节相对于近节的弯曲角；左指绕世界 Z 轴旋转 180° 得到。世界坐标中右侧近端轴心为 (29.925, 0, 14.9383) mm。

相对于近端轴心，名义末端坐标为：

```
x = L₁ cos(q₁) + L₂ cos(q₁+q₂)
z = L₁ sin(q₁) + L₂ sin(q₁+q₂)
J = [[−L₁ sin(q₁)−L₂ sin(q₁+q₂), −L₂ sin(q₁+q₂)],
     [ L₁ cos(q₁)+L₂ cos(q₁+q₂),  L₂ cos(q₁+q₂)]]
Δs = r₁(q₁−q₁₀) + r₂(q₂−q₂₀)
```

公式中的角度用弧度。q₁₀=q₂₀=15° 是研究零位，不是实测机械限位。J 经中心差分核对。

## 3. 回位、接触与欠驱动闭合

采用等效关节弹簧 τs=K(q−q₀)，K₁=20、K₂=40 N·mm/rad。它们是待实现和测量的设计目标，不能标注为原装拉簧刚度。对于真实拉簧，应根据两锚点求长度 ℓ(q)，再使用 τ=Fs(ℓ)·dℓ/dq，包含预紧力及力臂变化。

研究路径分为三段：

1. 未接触时 rT=K(q−q₀)，近端到达 55° 时，远端为 35°。
2. 规定近端接触使 q₁ 保持 55°，继续收绳，远端转至 90°。
3. 规定远端也接触，姿态保持 55°/90°，增大张力建立接触力。

这是**规定接触约束下的准静态闭合**，未把某个实际物体的接触搜索或动力学仿真伪装成已完成。弹性腱绳、关节摩擦、间隙和惯性未包含在本模型内。

## 4. 张力、关节力矩与接触力

近、远节的接触点距相应轴心分别为 c₁=35、c₂=25 mm，接触方向垂直于各指节；接触面离中心线 h=13.5 mm。该 h 为研究接触平面偏置，不代表已验证的浇注垫厚度。令 N₁、N₂ 为物体作用于手指的压缩法向力，则虚功平衡为：

```
A N + τs = r T
A = [[c₁, c₂ + L₁ cos(q₂)],
     [ 0, c₂               ]]
N₂ = (r₂T − τs₂)/c₂
N₁ = [r₁T − τs₁ − (c₂+L₁cos(q₂))N₂]/c₁
```

必须满足 N₁≥0、N₂≥0；负值说明接触会脱开，不能拿负接触力继续宣称稳定包络抓取。A 由接触点坐标的数值微分独立复核，闭合路径的每一步均检查静力平衡。

在远端目标 N₂=5 N、55°/90° 姿态下，得到 T≈**22.17 N**，N₁≈**1.10 N**。在相同目标力及 q₁=55° 下，对 q₂ 进行 1° 采样，双接触非负条件从约 84° 起成立；这同时说明工作姿态不能随意选。该结果只适用于声明的弹簧、力臂和接触假设，不等于夹爪额定抓取力。

## 5. 驱动需求与候选核对

按效率 η=0.75、载荷系数 1.5，执行器输出轴需求为：

```
τmotor = T·rm/η
τdesign = 1.5·T·rm/η ≈ 0.477 N·m
Δs ≈ 16.06 mm；Δφ ≈ 85.58°
若目标闭合时间为 1 s，平均输出轴转速约 14.26 rpm
```

效率 0.65–0.85 的参数扫描对应约 0.550–0.421 N·m。该系数用于研究损耗敏感性，不是对腱绳摩擦的测量。完整行程不足一圈，仍需确认走线、绕线层数及固定端防滑。

以兼容原安装方案的两台 MX-28 为初步候选。[ROBOTIS 官方手册](https://emanual.robotis.com/docs/en/dxl/mx/mx-28/)列出 12 V 时堵转转矩 2.5 N·m、空载转速 55 rpm，并明确堵转能力不同于持续输出。这里只完成需求计算和候选规格核对，**未证明连续工作、热平衡或带载速度合格**。需用转矩—速度曲线及占空比试验完成最终选型；不以“堵转转矩/需求转矩”充当安全系数。

## 6. 向结构模型传递载荷

把一侧手指、支座及其内部腱绳段作为一个整体，内部关节力与弹簧力相互抵消；外力包含两接触力和进入上部组件的竖直腱绳拉力。计算力矩时使用实际重建的轴心位置、接触点及走线入口，不能漏掉这根向下拉的腱绳。

在右侧座面中心 (31.3,0,0.003) mm 处的等效结果为：

| 项目 | 名义研究载荷 | 乘 1.5 后 |
|---|---:|---:|
| Fx / N | +3.7665 | +5.6498 |
| Fz / N | −18.7035 | −28.0552 |
| My / N·mm | +426.7192 | +640.0788 |

左侧 Fx、My 镜像反号，Fz 同号。有限元载荷向量再次独立检查每侧的合力和合矩。

**装配传力边界：**支座由下方装入，顶板、支座法兰与下部支承共同形成约束。新增顶板计算人为把上述合力和力矩全部映射到四条座面，作为明确的等效牵引场景；它不是已经求出的上下板实际分载，也不能保证对任意接触分布都保守。真实装配接触、预紧和下部件仍需专门模型或测试。
